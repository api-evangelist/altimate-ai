Altimate AI is an agentic data engineering platform that gives data teams AI "Datamates" — trustworthy agents that build data pipelines, migrate workloads, manage infrastructure, optimize warehouse cost, and enforce data governance across dbt, Snowflake, Databricks, Airflow and more. It is delivered through an MCP engine and IDE/agent integrations (Cursor, Claude Code, VS Code, GitHub Copilot, Windsurf, Gemini CLI), an open-source terminal harness (altimate-code), the DataPilot CLI, and the Power User for dbt extension. The platform is tech-stack agnostic, token-efficient, and open source, and exposes a large REST API at api.myaltimate.com covering queries, lineage, data contracts, governance, cost, and AI studio surfaces. SOC 2 Type II audited.

**Areas:** Company · Data · Data Engineering · Artificial Intelligence · Agents · MCP · dbt · Data Governance · Data Contracts · Analytics Engineering

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Altimate AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
